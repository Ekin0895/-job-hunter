Configuration de la connexion Google

L’adresse de l’application doit être autorisée dans ce client Google. Aucun mot de passe ni jeton n’est enregistré dans le code.

Les réglages sont mémorisés sur cet appareil. Le jeton Google reste uniquement en mémoire et expire ; une reconnexion pourra être nécessaire.

Ma recherche, mes critères

Choisissez plusieurs contrats, métiers ou zones. Les critères enregistrés seront lus par Work lors de sa prochaine recherche ; vos candidatures existantes sont conservées.

Le salaire minimum est un seuil d’exclusion. Le salaire cible et le télétravail sont des préférences, sauf si vous rendez le télétravail obligatoire. Le trajet n’inclut pas domicile → gare ni l’attente.

Ajouter une annonce

Aucune annonce n’est extraite tant que Work ne l’a pas traitée. Une demande enregistrée apparaît dans la file de traitement.
