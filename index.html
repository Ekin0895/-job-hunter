Répartition des candidatures

Ton workflow

1. Ajoute une offre réelle et son lien de candidature. 2. Associe ton CV Google Docs, ton PDF et ta lettre. 3. Change le statut au fil de tes démarches. 4. Sauvegarde régulièrement tes données en JSON.

La recherche automatique et la génération de PDF ne sont pas encore connectées. L'application n'affiche jamais de fausses offres ni de faux documents.

Déplace les cartes entre les colonnes pour modifier leur statut. Tu peux aussi utiliser les boutons « Étape suivante ».

Bibliothèque de candidatures

Les liens Google Docs, PDF et lettres doivent être renseignés pour chaque offre. Aucun fichier n'est créé automatiquement dans cette version.

Mes critères de recherche

Paramètres indépendants pour chaque catégorie.

Important : les réglages de cette application locale ne sont pas automatiquement accessibles à la recherche quotidienne ChatGPT. Copie les consignes dans ChatGPT pour mettre à jour la recherche.

Gestion des données

Tes offres sont conservées dans le stockage local de ce navigateur, sur cet appareil. Une sauvegarde JSON te permet de les transférer ou de les restaurer.

Attention : supprimer les données du navigateur peut effacer ton historique local. Exporte un fichier JSON régulièrement.
